# 영화 감상 측정기 (film-appreciation-meter)

학생이 영화를 보고 쓴 감상문을 문장 단위로 나누어, 각 문장이 **지각·이해·해석·평가**(순서 없는 네 서랍) 가운데 어느 서랍을 열었는지, 또는 층 밖의 **향유·참여**인지 판정하고 학생별 **감상 프로파일**을 그립니다. 같은 문장을 사람이 판정하면 프로그램 판정과의 **일치도(Cohen’s κ)**를 잽니다.

디지털도서관연구(2026-2) 기말 프로그램입니다. 9/12 수업에서 정한 주제(영화 감상 능력 측정 도구 + 영화 감상 온톨로지)를 교수님이 제시한 조건(① 온톨로지로 구조화 ② 내 전문지식 ③ 지침은 문서로 ④ 검증)에 맞춰 구현했습니다.

- 사이트: https://film-appreciation-meter.web.app (로그인 없음, 기록은 이 브라우저에만)
- 같은 구조의 앞 과제: [ANT 개념도 생성기](https://github.com/inbluewater-dev/ant-concept-map)

## 하는 일

| 단계 | 내용 |
| --- | --- |
| 판정 기준 | `src/data/film-appreciation.ttl`(영화 감상 측정 온톨로지 v0.2)을 프로그램이 **그대로 읽어** AI 지침을 만든다. 차원 정의, 판정 지표(조건), 연 예·열지 않은 예와 그 까닭, 교과서 쪽수 근거. 지표를 고치려면 TTL을 고친다 |
| 문장 나누기 | 프로그램이 규칙(문장 부호·줄바꿈)으로 나눈다. 프로그램과 사람이 같은 단위를 판정해야 일치도를 잴 수 있으므로 AI에게 맡기지 않는다 |
| AI 판정 | Gemini(Firebase AI Logic, JSON 스키마 강제). 문장마다 주 차원 1 + 보조 1까지, 적용한 지표, 까닭, 근거 인용. 빠진 문장이 있으면 한 번 더 받는다 |
| 근거 대조 | AI가 근거로 든 구절이 그 문장에 정말 있는지 프로그램이 대조(있음/부분 일치/없음) |
| 감상 프로파일 | 연 서랍은 앞으로 빠져나온 서랍장 그림(PNG/SVG). 향유·참여는 층 밖 선반. 열지 않은 서랍을 겨냥한 발문을 **온톨로지에서** 골라 보여 줌 |
| 사람 판정 | 평정자 이름별로 문장마다 주·보조 차원을 고른다. AI 판정은 기본으로 가려 둔다(눈가림) |
| 일치도 | AI·평정자·사람 합의(모든 사람 평정자가 같은 주 차원을 준 문장, Purves의 절차) 가운데 둘을 골라 주 차원 일치율, Cohen’s κ(6범주), 차원별 κ, 혼동표, 갈린 문장. 해석은 Landis & Koch(1977) |
| 연구 자료 | JSON 내보내기·가져오기(평정자별 판정 합치기), 문장별 CSV(엑셀·SPSS·R) |

## 정한 것 (2026-11-10)

- 측정 본체는 **자유 감상문 한 편**(발문 1). 발문 2~7은 열지 않은 서랍을 여는 수업 발문으로 쓴다.
- 한 문장에 **주 차원 1 + 보조 1**까지. 일치도는 주 차원끼리 비교한다.
- 어느 지표에도 맞지 않는 문장은 **기타**(Purves 500).
- 근거 없는 좋고 싫음("재미있었다")은 **향유·참여**(「영화 감상과 비평」 p.21, 11/3 결정).
- 시연·검증은 **교과서 예시 문장과 가상 감상문**으로 한다(실제 학생 자료 없음). 앱의 가상 감상문 A~D는 설계용으로 새로 쓴 글이다.

## 이론적 바탕

- Purves, A. C., & Rippere, V. (1968). *Elements of Writing about a Literary Work*. NCTE. — 문장 단위 반응 분류(참여 100·지각 200·해석 300·평가 400·기타 500). 이 도구의 지각 층은 영화에만 있는 층으로 새로 더했다(Purves의 Perception은 '이해'에 대응).
- OECD(2019). PISA 2018 Released Reading Items — 채점 지침의 꼴(정답 조건 + 예시 응답)을 판정 지표의 꼴로 썼다.
- 「영화와 삶」, 「영화 감상과 비평」, 「영화의 이해」(2022 개정 고등학교 교과서) — 차원 정의와 예시 진술의 근거(쪽수는 TTL에).
- Cohen, J. (1960). A coefficient of agreement for nominal scales. / Landis, J. R., & Koch, G. G. (1977). The measurement of observer agreement for categorical data.

## 개인정보

감상문은 AI(Google Gemini 무료 등급)로 보내지며 Google 제품 개선에 쓰일 수 있습니다. 이름·학교 등은 지우고 '학생 1'처럼 넣습니다. 실제 학생 연구에는 연구 동의와 유료 등급 전환을 검토해야 합니다.

## 실행

```bash
npm install
npm run dev          # 샘플 모드(낱말 규칙으로 흉내 낸 판정, 인터넷 불필요)
npm test             # 단위 테스트
npm run test:e2e     # 화면 테스트(샘플 모드)
```

실제 AI는 `.env.local`에 `VITE_AI_MODE=gemini`와 Firebase 값(`.env.example` 참고)을 넣습니다. ANT 개념도 생성기·영화 수업 설계 도우미와 같은 Firebase 프로젝트(`film-reading-lesson`)를 씁니다. main에 올리면 GitHub Actions가 테스트 후 Firebase 호스팅(`film-appreciation-meter` 사이트)에 배포합니다.
